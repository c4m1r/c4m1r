# Windows XP Desktop Recreation

## 🖥️ О проекте

Веб-приложение на **Rust Axum**, точно воспроизводящее интерфейс Windows XP с полным набором приложений и конфигурационной системой.

**Основные возможности:**
- 📋 **JSON-based конфигурация** всех приложений и системных настроек
- 🎨 **Точная имитация** интерфейса Windows XP
- 🧹 **Оригинальные приложения** из OnlineWinXP-master
- 🌐 **Поддержка iframe** для внешних сайтов
- ⚙️ **Гибкая настройка** через конфигурационные файлы

## 🚀 Быстрый запуск

### Windows
```powershell
# Режим разработки
.\bin\dev.ps1

# Production запуск
.\bin\run.ps1 -Release

# Автотесты
.\bin\autotests.ps1
```

### Linux/Mac
```bash
# Режим разработки
./bin/dev.sh

# Production запуск
./bin/run.sh

# Автотесты
./bin/autotests.sh
```

Сервер запустится на `http://localhost:3000`

## 🎯 Функциональность

### Рабочий стол
- Фоновое изображение Windows XP
- Иконки приложений с двойным кликом для запуска
- Выделение области мышкой
- Контекстное меню (правый клик)

### Окна
- Перетаскивание окон
- Изменение размера (для поддерживаемых приложений)
- Минимизация/максимизация/закрытие
- Z-index управление (активное окно сверху)

### Панель задач
- Кнопка "Пуск" с меню
- Отображение открытых приложений
- Часы в системном трее

### Приложения
- 🧹 **Minesweeper** - оригинальная реализация из OnlineWinXP-master
- 📝 **Notepad** - текстовый редактор
- 🌐 **Internet Explorer** - имитация браузера
- 🎨 **Paint** - приложение для рисования
- 🎵 **Winamp** - музыкальный плеер
- 💻 **My Computer** - просмотр системных папок
- 🌐 **Iframe приложения** - поддержка внешних сайтов в окнах

### Меню "Пуск"
- Доступ к программам
- Выключение компьютера
- Логотип Windows XP

## 🛠 Технический стек

- **Backend**: Rust + Axum веб-фреймворк
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Конфигурация**: JSON-based система настроек приложений
- **Стилизация**: CSS с Windows XP темой
- **Архитектура**: SPA с динамической загрузкой контента и поддержкой iframe

## 🔌 API Endpoints

Сервер предоставляет следующие REST API endpoints:

### Health Check
```
GET /health
```
Возвращает статус сервера в формате JSON:
```json
{
  "status": "ok",
  "version": "0.1.0",
  "timestamp": 1763633938
}
```

### Список приложений
```
GET /api/apps
```
Возвращает список доступных приложений:
```json
{
  "apps": [
    {
      "id": "minesweeper",
      "name": "Minesweeper",
      "icon": "/static/images/minesweeper/mine-icon.png"
    }
  ]
}
```

### Проверка приложения
```
GET /apps/{app_id}
```
Проверяет доступность конкретного приложения.

### Конфигурация системы
```
GET /api/config
```
Возвращает полную конфигурацию системы в формате JSON:
```json
{
  "apps": { /* настройки приложений */ },
  "desktopIcons": [ /* иконки рабочего стола */ ],
  "folders": { /* системные папки */ },
  "drives": { /* диски */ },
  "startMenuItems": [ /* элементы меню Пуск */ ],
  "iframeApps": { /* iframe приложения */ },
  "systemSettings": { /* системные настройки */ }
}
```

### Статические файлы
```
GET /static/*
```
Обслуживание статических файлов (CSS, JS, изображения, конфигурация).

## 🧪 Автотестирование

Проект включает полную систему автотестов для проверки функциональности:

### Запуск тестов

#### Windows
```powershell
# Полный набор тестов с запуском сервера
.\bin\autotests.ps1

# Только тесты (сервер уже запущен)
.\bin\autotests.ps1 -NoServer

# Подробный вывод
.\bin\autotests.ps1 -Verbose
```

#### Linux/Mac
```bash
# Полный набор тестов
./bin/autotests.sh

# Только тесты (сервер уже запущен)
NO_SERVER=true ./bin/autotests.sh

# Подробный вывод
VERBOSE=true ./bin/autotests.sh
```

## 🛠 Добавление новых приложений

### Локальные приложения
1. Добавьте настройки в `config.json`:
```json
"my-app": {
  "name": "My App",
  "icon": "/static/images/my-app.png",
  "type": "local",
  "defaultSize": { "width": 400, "height": 300 },
  "resizable": true,
  "jsFiles": ["my-app.js"],
  "cssFiles": ["my-app.css"]
}
```

2. Реализуйте функцию в `static/js/apps.js`:
```javascript
Window.prototype.loadMyApp = function(contentDiv) {
    // Ваш код приложения
};
```

### Iframe приложения (внешние сайты)
```json
"external-site": {
  "name": "External Site",
  "icon": "/static/images/web.png",
  "type": "iframe",
  "url": "https://example.com",
  "defaultSize": { "width": 800, "height": 600 },
  "resizable": true
}
```
