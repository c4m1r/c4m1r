# Welcome to My Portfolio

## About This Project

This is a **Windows XP-style** portfolio website built with modern web technologies.

### Features

- 🎨 Authentic Windows XP design
- 📱 Multiple applications
- 🎵 Music players (Winamp & Windows Media Player)
- 🎮 Games (Doom, Minesweeper)
- 📝 Productivity tools

## Applications

| App | Description |
|-----|-------------|
| Notepad | Text editor with markdown support |
