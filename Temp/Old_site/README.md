# Статический сайт c4m1r.github.io

Этот проект содержит статический сайт, собранный из компонентов темы Hexo Kuri.

## Структура проекта

```
site/
├── _config.yml          # Конфигурация темы
├── build.js             # Скрипт сборки статического сайта
├── build.sh             # Скрипт для Linux/Mac
├── build.ps1            # Скрипт для Windows PowerShell
├── package.json         # Зависимости и скрипты npm
├── layout/              # EJS шаблоны
│   ├── index.ejs
│   ├── layout.ejs
│   ├── _partial/
│   └── _widget/
└── source/              # Статические ресурсы
    ├── css/
    ├── js/
    ├── images/
    ├── fonts/
    └── icons/
```

## Установка

1. Установите Node.js (версия 20 или выше)
2. Установите зависимости:

```bash
cd site
npm install
```

## Сборка

### Автоматическая сборка и запуск локального сервера

**Linux/Mac:**
```bash
./build.sh
```

**Windows PowerShell:**
```powershell
.\build.ps1
```

### Ручная сборка

```bash
npm run build
```

Собранный сайт будет находиться в папке `public/`.

### Локальный запуск

```bash
npm run serve
```

Сайт будет доступен по адресу: http://localhost:4000

## Конфигурация

Отредактируйте файл `_config.yml` для настройки:

- **nickname** - Ваше имя/никнейм
- **motto** - Краткое описание
- **logo** - Путь к аватару (например, `/images/avatar.jpg`)
- **github** - Ссылка на GitHub профиль
- **background** - Массив URL фоновых изображений
- **sidebar** - Настройки бокового меню
- **social** - Социальные кнопки
- **aplayer** - Настройки музыкального плеера (если нужен)

## Публикация на GitHub Pages

Проект настроен для автоматической публикации через GitHub Actions.

1. Убедитесь, что в репозитории включен GitHub Pages в настройках
2. При каждом push в ветку `main` или `master` сайт автоматически соберется и опубликуется
3. Сайт будет доступен по адресу: https://c4m1r.github.io

## Ручная публикация

Если нужно опубликовать вручную:

1. Выполните сборку: `npm run build`
2. Скопируйте содержимое папки `public/` в ветку `gh-pages` или в корень репозитория (в зависимости от настроек GitHub Pages)

## Разработка

При изменении шаблонов или конфигурации:

1. Внесите изменения в файлы
2. Запустите сборку: `npm run build`
3. Проверьте результат локально: `npm run serve`
4. Закоммитьте изменения и запушьте в репозиторий

## Примечания

- Все статические ресурсы (CSS, JS, изображения) копируются в соответствующие папки в `public/`
- Пути в HTML автоматически корректируются для работы на GitHub Pages
- Скрипт сборки обрабатывает EJS шаблоны и заменяет переменные из `_config.yml`
