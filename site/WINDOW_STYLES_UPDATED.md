## 🎯 ДОБАВЛЕННЫЕ ФУНКЦИИ

### ✅ Кнопки управления окном
- **Закрыть** - красный градиент с крестиком (×)
- **Свернуть** - синий градиент с горизонтальной линией (—)
- **Развернуть** - синий градиент с квадратом (□)
- **Восстановить** - синий градиент с двумя квадратами

### ✅ Улучшенные градиенты заголовка
- **Активное окно**: сложный синий градиент (12 ступеней)
- **Неактивное окно**: серый градиент с 12 ступенями
- **Тень текста**: `text-shadow: 1px 1px 0 rgba(0, 0, 0, 0.6)`

### ✅ Реалистичная рамка окна
- **Внутренняя подсветка**: белые и черные inset-тени
- **Внешняя тень**: `2px 2px 4px rgba(0, 0, 0, 0.3)`
- **Граница**: 3px синяя рамка

### ✅ Иконка в заголовке
- **Размер**: 16×16px
- **Фильтр**: белая подсветка для контраста
- **Позиция**: слева от текста заголовка

### ✅ Стили менюбара
- **Hover**: светло-синий градиент с рамкой
- **Active**: инвертированный градиент с затемнением
- **Переходы**: плавная анимация 0.1s

### ✅ Поверхность контента
- **Фон**: `#ece9d8` (классический XP)
- **Граница**: 3D inset-стиль (светлые/темные края)
- **Padding**: 8px

### ✅ Скроллбары в стиле XP
- **Ширина**: 18px
- **Трек**: градиентный фон с границей
- **Ползунок**: серый градиент с 3D эффектом
- **Hover**: светлее при наведении

## 🎨 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Градиенты кнопок (как в оригинале):
```css
/* Закрыть - красный */
background: radial-gradient(circle at 90% 90%,
  rgb(204, 70, 0) 0%,
  rgb(220, 101, 39) 55%,
  rgb(205, 117, 70) 70%,
  rgb(255, 204, 178) 90%,
  white 100%
);

/* Свернуть/Развернуть - синий */
background: radial-gradient(circle at 90% 90%,
  rgb(0, 84, 233) 0%,
  rgb(34, 99, 213) 55%,
  rgb(68, 121, 228) 70%,
  rgb(163, 187, 236) 90%,
  white 100%
);
```

### Символы кнопок (через псевдоэлементы):
```css
/* Крестик закрытия */
.close::before, .close::after {
  width: 12px;
  height: 2px;
  background: white;
  transform: rotate(45deg); /* и -45deg */
}

/* Линия сворачивания */
.minimize::before {
  width: 8px;
  height: 1px;
  background: white;
}

/* Квадрат разворачивания */
.maximize::before {
  box-shadow: white 0px 3px inset,
              white 0px 0px 0px 1px inset;
  width: 9px;
  height: 7px;
}
```

### 3D эффекты окон:
```css
/* Рамка окна */
box-shadow:
  1px 1px 0px rgba(255, 255, 255, 0.4) inset,
  -1px -1px 0px rgba(0, 0, 0, 0.2) inset,
  2px 2px 4px rgba(0, 0, 0, 0.3);

/* Поверхность контента */
border-left: 1px solid #d1cfc6;   /* светлый */
border-top: 1px solid #d1cfc6;    /* светлый */
border-right: 1px solid #8e8b7e;  /* темный */
border-bottom: 1px solid #8e8b7e; /* темный */
```
